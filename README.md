## 1. Instalasi via Git Clone

```bash
git clone https://github.com/InstaCodex/AuthBase.git
cd AuthBase
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
npm install
npm run dev
php artisan serve
```

---

## 2. Instalasi via Download ZIP

1. Buka repository GitHub
2. Klik **Code → Download ZIP**
3. Ekstrak file ZIP
4. Masuk ke folder project
```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
npm install
npm run dev
php artisan serve
```

---

## 3. Instalasi via Composer (Packagist)

```bash
composer create-project instacodex/authbase
cd authbase
cp .env.example .env
php artisan key:generate
php artisan migrate
npm install
npm run dev
php artisan serve
```

---

Buka di browser:

```
http://127.0.0.1:8000
```
